# Kő Papír Olló Gyík Spock

Böngészőalapú implementációja a klasszikus Kő Papír Olló Gyík Spock játéknak, többnyelvű támogatással, sötét/világos üzemmóddal és helyi statisztikákkal.

## Funkciók

- Klasszikus KPOGS szabályok
- Három nyelv: magyar, angol, német
- Sötét és világos üzemmód, mentett préferencia
- Helyi játékstatisztikák a böngésző tárolójában
- Reszponzív dizájn asztali és mobilos eszközökhöz
- Animált betöltőképernyő és játékátváltások

## Technológiák

- HTML5
- CSS3 (Flexbox, CSS animációk)
- Vanilla JavaScript (ES6 osztály alapú architektúra)

## Kezdés

1. Klónozd vagy töltsd le a repót
2. Nyisd meg az `index.html`-t bármely modern böngészőben
3. Nincs build lépés vagy függőség

## Hogyan kell játszani

1. A nyilakkal válaszd ki a dobásod
2. Nyomd meg a pipa gombot a kör indításához
3. Nézd a számítógép választásának animációját
4. Nézd meg az eredményt és a frissített statisztikákat
